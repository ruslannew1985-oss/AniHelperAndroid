# Ани — Android-помощница (исходный проект)

Это **исходный проект MVP**, а не уже собранный APK. В среде подготовки не обнаружен Android SDK/Gradle, поэтому готовый APK здесь не был собран и не прошёл запуск на физическом телефоне.

## Уже реализовано в исходниках
- Плавающая картинка поверх других приложений с перетаскиванием.
- Нажатие на персонажа открывает окно чата.
- Текстовый диалог через OpenAI Responses API (настраиваемые endpoint и модель).
- Озвучивание ответов системным Android TextToSpeech на русском языке.
- Ввод голосом через системное распознавание речи.
- Экран настройки API-ключа, модели и endpoint.

## Важные ограничения первого прототипа
- Персонаж пока статичная картинка, без моргания/анимации.
- Голосовой ввод использует установленную на телефоне службу распознавания речи; доступность офлайн-режима зависит от Android/Google.
- Для ИИ нужен отдельный API-ключ и оплачиваемый/доступный API аккаунт. Подписка ChatGPT сама по себе не включает API-кредиты.
- Для реального приложения ключ API нельзя встраивать в публичную сборку: безопаснее добавить собственный сервер-посредник. В этом прототипе ключ хранится в локальных настройках телефона, но это не решение для публикации.
- Текущая реализация отправляет только текущий вопрос; полная история диалога и потоковая речь пока не реализованы.
- Приложение targetSdk 28 выбран намеренно для MVP overlay-проверки. Для публикации надо обновить target SDK и проверить актуальные правила Android/Google Play.

## Сборка APK на компьютере
1. Установить Android Studio и Android SDK (API 35).
2. Открыть папку `AniHelperAndroid` в Android Studio.
3. Дождаться синхронизации Gradle.
4. Build → Build APK(s).
5. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка и тест
1. Установить APK на Android-телефон.
2. Открыть «Ани — помощница», указать API-ключ, модель и endpoint.
3. Нажать «Включить плавающую Ани» и выдать разрешение «Поверх других приложений».
4. Нажать на персонажа — откроется чат.
5. Отправить короткий вопрос и проверить текстовый ответ и озвучивание.
6. Нажать микрофон и проверить распознавание русской речи.
7. Проверить перетаскивание персонажа и остановку через главное окно.

## Endpoint
По умолчанию: `https://api.openai.com/v1/responses`

Модель в поле настроек должна быть доступна вашему API-проекту. При использовании другого совместимого провайдера необходимо указать его endpoint и подходящее имя модели; формат должен соответствовать OpenAI Responses API.
