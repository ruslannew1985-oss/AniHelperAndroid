# Ронин + GPT в Telegram

Отдельный текстовый бот для одного владельца. Python 3.10+ без сторонних библиотек.
Режимы «🥷 Ронин» и «💬 GPT», переключение кнопками, отдельная память последних
10 пар сообщений для каждого режима. Память переживает перезапуск.

**Статус:** код подготовлен, тесты с подменёнными API; реальный запуск требует
токенов и хостинга. В Android MainActivity пока только локальные команды.
Ронин в боте — персонаж на базе GPT, не удалённое управление Android-приложением.
История вашего аккаунта ChatGPT в бот не переносится.

## Подготовка

1. В https://t.me/BotFather отправить `/newbot`, выбрать имя и свободный username,
   оканчивающийся на `bot`. Сохранить токен; не выкладывать его в чат или GitHub.
2. Создать API key в своём OpenAI API проекте и настроить оплату API.
   Подписка ChatGPT не является API-ключом. Выбрать доступную в проекте текстовую
   модель с поддержкой Responses API; её точное имя вводится при настройке.
3. Узнать свой числовой Telegram user ID (например, в экспорте своих данных
   Telegram Desktop). Это не username и не номер телефона. Доступ закрыт всем
   другим пользователям и групповым чатам.
4. Скопировать папку `telegram-bot` на постоянно включённый компьютер или сервер
   с Python 3.10+ и доступом к Telegram/OpenAI. На время первого запуска достаточно
   открытого терминала; его закрытие останавливает бота. GitHub хранит код,
   GitHub Actions не используется как постоянный хостинг.

## Запуск

В терминале внутри папки `telegram-bot`:

```sh
python3 bot.py --setup
python3 bot.py
```

Первый запуск настройки спрашивает токен Telegram, ключ OpenAI (оба вводятся
скрыто), имя модели и ID владельца. Сохраняет локальный `.env` с правами 0600.
Повторно запускать setup не надо; для смены настроек отредактируйте `.env` локально.
Можно вместо файла задать переменные окружения `TELEGRAM_BOT_TOKEN`,
`OPENAI_API_KEY`, `OPENAI_MODEL`, `OWNER_ID` в секретах вашего сервера.
Никогда не помещайте реальные значения в репозиторий.

Открыть своего бота в Telegram, нажать «Начать» и выбрать режим.
Команды: `/ronin`, `/gpt`, `/new` (сброс текущей истории), `/forget` (обе истории), `/help`.
Сообщения и контекст отправляются в OpenAI; локальная история хранится в
`history.sqlite3`. `/forget` удаляет её содержимое, но не удаляет сообщения
из Telegram и не гарантирует удаление данных из внешних журналов провайдера.

## Проверка и ограничения

```sh
python3 -m unittest -v
```

Только текст. Фото, голос, инструменты, поиск и управление телефоном не подключены.
Оба режима используют одну выбранную модель и отличаются инструкциями и историей.
Не запускайте две копии с одним токеном. Webhook не отключается автоматически.
При ошибке API бот просит повторить вопрос; оплачиваемые запросы автоматически
не повторяются. При аварии во время обработки возможна потеря одного входящего
сообщения; отправьте его заново. Доставка ответа при сетевом сбое не гарантируется.
Для постоянного запуска используйте менеджер процессов на выбранном сервере;
конкретное размещение пока не настроено.

Документация: https://core.telegram.org/bots/api и
https://developers.openai.com/api/docs/guides/text
