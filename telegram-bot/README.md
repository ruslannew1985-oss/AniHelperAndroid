# Ронин в Telegram — без платного ИИ

Текстовый бот для одного владельца. Ключ OpenAI и баланс API не требуются.
В программе нет обращений к OpenAI или другим ИИ-провайдерам.
Возможности: кнопки меню, заметки, список дел, отметка выполнения, удаление заметок.
Свободного ИИ-диалога, голосовых сообщений и управления Android пока нет.

## Запуск
Нужен Python 3.10+ на вашем компьютере или телефоне с Python-окружением,
интернет и действующий токен Telegram. Сторонних Python-библиотек нет.
Сам бот не требует платы за ИИ; интернет, электричество и возможная аренда
сервера оплачиваются отдельно. Для запуска без аренды можно использовать
своё устройство. Когда оно выключено или процесс остановлен, бот не отвечает.

В папке telegram-bot:
```sh
python3 bot.py --setup
python3 bot.py
```
Настройка спрашивает только токен Telegram (скрыто) и числовой Telegram ID владельца.
Хранит их в локальном .env с правами 0600. Не публикуйте .env и токен.
Альтернатива — переменные окружения TELEGRAM_BOT_TOKEN и OWNER_ID.
Старые настройки OPENAI_API_KEY и OPENAI_MODEL игнорируются, их можно удалить
из локального .env. Не присылайте ключи в переписку.

## Команды
- /start и /help — меню.
- /note текст и /notes — сохранить и показать заметки.
- /todo текст и /todos — добавить и показать дела.
- /done номер — отметить дело выполненным.
- /delete номер — удалить заметку.
- /cancel — отменить ожидаемый ввод.
Номера общие для заметок и дел. Максимум 100 записей каждого вида, 4000 символов
на запись. Выполненные дела остаются в списке и учитываются в лимите.
Неизвестный текст не сохраняется автоматически.

Данные хранятся в history.sqlite3 и переживают перезапуск. Сделайте резервную
копию этого файла при остановленном боте. Удаление заметки из базы не удаляет
её из переписки Telegram. Бот принимает сообщения только владельца в личном чате.
Не запускайте две копии с одним токеном. Существующий webhook не удаляется.
При аварии во время обработки возможна потеря одного сообщения — отправьте снова.
При сбое отправки ответа запись уже может быть сохранена: проверьте список.

## Проверка
```sh
python3 -m unittest -v
```
Проверены команды, сохранение после перезапуска, доступ и отсутствие запросов
к ИИ с подменой Telegram API. Реальный запуск не выполнен: токен и устройство
запуска пользователь ещё не настроил. Android-приложение не изменялось.
